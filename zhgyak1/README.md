# zhgyak1

Programozás 5 gyakorlófeladat, a jelenlegi munkaváltozattal.

A Maven-projekt helye: `zh-vaadin/zh-vaadin/pom.xml`.
Szükséges JDK: **Java 21** (a pom.xml alapján).

IntelliJben a fenti pom.xml fájlt nyisd meg Maven-projektként.

Indítás PowerShellből, ennek a gyakorlófeladatnak a mappájából:

```powershell
cd zh-vaadin/zh-vaadin
.\mvnw.cmd spring-boot:run
```

A forráskódok, Maven Wrapper és a rendelkezésre álló feladatleírások verziókövetettek.
A generált fájlok, buildkimenetek, naplók és helyi IDE-beállítások kimaradnak.
