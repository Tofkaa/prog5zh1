# Saját gyakorlófeladatok

Saját Programozás 5 ZH-gyakorlófeladatok és megoldások.

A ZH során **kizárólag a könyvtáras feladatot (`zhgyak3-konyvtar`) és az órai anyagot néztem segítségként, kódblokkok másolása nélkül**. A ZH ideje alatt a repository egyetlen másik mappáját sem nyitottam meg.

A könyvtáras feladat saját készítésű gyakorlófeladat, amelyet kézzel oldottam meg. A megoldás elkészítése után AI is végezhetett benne javításokat. Az [eredeti Markdown-feladatleírás](zhgyak3-konyvtar/FELADATLEIRAS.md) is megtalálható a repositoryban, így látható, milyen követelmények alapján készült a megoldás.

| Mappa | Alapfeladat |
| --- | --- |
| `zhgyak1` | Kisállat-nyilvántartó ZH-feladat megoldása. |
| `zhgyak2` | Ugyanannak a kisállat-nyilvántartó ZH-feladatnak egy másik megoldása. |
| `zhgyakMAGAMTOL` | A kisállat-nyilvántartó ZH-feladat önállóan elkészített megoldása. |
| `zhgyak3-konyvtar` | Könyvtári nyilvántartó gyakorlófeladat megoldása. |
| `zhgyak4-eszkozok` | Egyetemi eszköznyilvántartó gyakorlófeladat megoldása. |
